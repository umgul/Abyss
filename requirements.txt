# Abyss funciona con la biblioteca estándar de Python 3.12+ salvo para piezas opcionales.
# Todas van comentadas a propósito: instala solo la que necesites (quita el # de su línea),
# o mejor, deja que el propio paquete lo resuelva por ti (quinta tanda):
#
#   python instalar.py --dependencias                  (qué falta, por módulo, con tamaño aprox.)
#   python instalar.py --instalar-dependencias imagen   (instala SOLO lo que de verdad falte)
#
# --instalar-dependencias comprueba con un `import` real bajo el intérprete que se vaya a
# usar (nunca una lista fija) y enseña el comando `pip install` exacto ANTES de correrlo, uno
# a uno — este fichero es la referencia legible/instalable a mano cuando no se usa el
# instalador; los dos deben decir lo mismo (`DEPENDENCIAS` en instalar.py es la fuente viva).
# Lo que ni el instalador ni este fichero pueden poner —binarios del sistema, nunca de pip—
# también sale de `--dependencias`: el motor de OCR en Linux/macOS (el paquete `tesseract` de
# tu gestor; el código llama al binario por PATH, nunca a `pytesseract`) y `torch`+`diffusers`
# para `taller.py` (pesan gigas y dependen de la tarjeta: `--dependencias` detecta si hay GPU
# NVIDIA y da el comando exacto, pero nunca instala nada de eso por su cuenta).
#
# - pintor.py (y el verbo "imagen.py pintar", que lo usa) necesitan Pillow y numpy para
#   pintar el cuadro de pinceladas localmente. Son imports de nivel de módulo: sin ellas,
#   `import pintor` falla con ModuleNotFoundError en el momento de importarlo (no hay
#   fallback silencioso a un dict con "error"). El verbo "crear" de imagen.py (la cascada
#   de proveedores) no las usa y sigue funcionando igual sin ellas.
# Pillow
# numpy
#
# - imagen.py video / video_pintura.py necesitan imageio-ffmpeg (trae su propio binario de
#   ffmpeg, no hace falta instalarlo aparte) para codificar el .mp4 a partir del .json.gz
#   que deja pintor.py. Sin ella, video() lanza RuntimeError con el motivo y la CLI imprime
#   "sin video: ..." (código 2), no revienta con una traza oscura.
# imageio-ffmpeg
#
# - ojo.py necesita opencv-python (el módulo `cv2`) para leer la webcam. Es OPCIONAL: sin
#   él, ojo.py imprime "sin cv2: no hay ojo" y sale con código 1. lienzo.py también la usa,
#   pero como OPCIONAL de verdad: sin ella, restaurar/numeros/borrar caen a un equivalente
#   en Python puro (más lento, o un paso que se salta con aviso) — nunca fallan del todo.
# opencv-python
#
# - lector_pdf.py necesita PyMuPDF (el módulo `fitz`) o pypdf para extraer texto de un PDF.
#   Con fitz, las secciones salen de tamaños de letra reales (mejor heurística); sin ninguna
#   de las dos, la CLI imprime "sin dato: pip install pymupdf" y sale con código 1 — nunca
#   inventa el texto del PDF.
# PyMuPDF
# pypdf
#
# - gestos.py (módulo propio del instalador, APAGADO por defecto) necesita mediapipe para el
#   vocabulario de manos sobre el vídeo de la cámara, y opencv-python + numpy para leerla y
#   calcular los landmarks. Sin mediapipe/opencv-python, el guion dice exactamente qué
#   instalar y sale con código 2 — nunca arranca a medias.
# mediapipe
#
# - taller.py (servidor local de texto→imagen para la vía "local" de imagen.py crear, y para
#   lienzo.py borrar --metodo taller) necesita diffusers + torch. Son PESADAS (GB de descarga
#   entre el propio paquete y el modelo) y torch cambia según tengas GPU NVIDIA o no — sigue
#   pytorch.org/get-started/locally para instalar la versión correcta en vez de "pip install
#   torch" a ciegas. Sin ellas, taller.py imprime el pip install exacto y sale con código 2;
#   ninguna otra pieza de este paquete las necesita.
# diffusers
# torch
